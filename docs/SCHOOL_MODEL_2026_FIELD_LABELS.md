# Field Labels

- school_ownership: Loại hình sở hữu
- organization_structure: Cấu trúc đơn vị
- merger_status: Trạng thái tổ chức
- campus_count: Số điểm/cơ sở
- delivery_model_current: Mô hình triển khai hiện tại
- delivery_model_proposed: Mô hình đề xuất
- teacher_source: Nguồn nhân sự đứng lớp
- payer_model: Nguồn chi/thu
- approval_status: Trạng thái phê duyệt
- policy_note: Ghi chú chính sách địa phương
